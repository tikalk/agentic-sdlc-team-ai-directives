# CDR-010: Mandatory Worktree Isolation for Autonomous Agent Missions

## Context

When multiple AI agents or user sessions execute tasks in parallel across branches, running commands (builds, checkouts, tests, commits) in the primary repository workspace causes collisions: uncommitted files get overwritten, stashes are disrupted, and untracked files leak across branches.

## Decision

All mission and feature implementations (`factory-mission`, code modification agents) MUST execute exclusively inside a dedicated git worktree located under `.adlc/worktrees/<run_id>/`. The agent is strictly prohibited from executing `git checkout`, `git switch`, `git reset`, or modifying source files in the primary repository checkout root.

## Rejected Alternatives

* Operating directly in primary root — leads to race conditions and loss of unstaged human/agent work during parallel execution.
* Auto-stashing in main root — unstashing often fails on merge conflicts and drops work when multiple runs overlap.

## Reason

Worktree isolation guarantees thread-safety for multi-agent workflows, ensures a pristine root state, and prevents cross-session state pollution.
