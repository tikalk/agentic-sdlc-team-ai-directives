# CDR-001: Description-as-trigger for skill discovery

## Context

Agent-skill routers match on frontmatter `description` to decide which skill to load. When descriptions summarize the workflow instead of the triggering situation, agents follow the summary as a shortcut and never read the skill body.

## Decision

Write skill frontmatter `description` as trigger conditions only — "Use when…" symptoms and situations — never as a workflow summary. Enforce with a unit test that descriptions start with "Use when".

## Rejected Alternatives

* Workflow summary in description — agents follow the shortcut instead of reading the body
* No convention, free-form descriptions — router matching degrades as the catalog grows

## Reason

The description is the trigger surface, not documentation. Trigger-only descriptions keep routing precise while forcing the agent to load the full skill for the actual procedure.
