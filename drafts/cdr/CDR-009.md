# CDR-009: Bilingual setup scripts (bash + PowerShell, same stem)

## Context

Deterministic skill setup steps (environment resolution, ID allocation, branch prep) must run identically for contributors on Linux/macOS and Windows. A single-shell script silently excludes half the team or forces ad-hoc translation.

## Decision

Ship every executable setup script as a functional pair with the same stem: `scripts/bash/setup-<skill>.sh` (`set -euo pipefail`) and `scripts/powershell/setup-<skill>.ps1` (`$ErrorActionPreference = "Stop"`), both emitting the same machine-readable contract (e.g. `--json`).

## Rejected Alternatives

* Bash-only scripts — excludes Windows contributors, invites ad-hoc ports that drift
* Inline shell in skill bodies — untestable, unrunnable, rots silently

## Reason

Same-stem pairing makes the second shell a first-class citizen rather than a port: one contract, two implementations, both runnable and reviewable side by side.
