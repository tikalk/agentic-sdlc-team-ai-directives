# CDR-003: Compact-index injection with on-demand full reads

## Context

Injecting full team-directive bodies into every session burns context on records most tasks never need, while injecting nothing leaves agents unaware the guidance exists.

## Decision

Inject only a compact descriptor index (IDs + one-line descriptors) at session start; the agent matches the index per task and reads full module bodies on demand. Keep the index small enough to be ever-present.

## Rejected Alternatives

* Full-body injection every session — context bloat, most records unused per task
* No injection, manual lookup — agents never discover relevant guidance

## Reason

The index is a routing table, not the content. It scales to large directive catalogs at fixed session-start cost while keeping full guidance exactly one read away.
