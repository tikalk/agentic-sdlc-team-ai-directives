# CDR-002: Baseline-first (RED-GREEN-REFACTOR) skill authoring

## Context

Skills written from intuition tend to address imagined failures and miss the real ones — agents rationalize around guidance that was never pressure-tested, so the skill looks complete but changes nothing.

## Decision

Before writing any skill guidance, run a pressure scenario without the skill and record the verbatim baseline failures; write minimal guidance that fixes only observed failures, then loop adding counters until bulletproof. A skill written before its baseline run is deleted, not patched.

## Rejected Alternatives

* Write guidance first, test after — fixes imagined failures, misses real rationalizations
* Patch a pre-baseline skill incrementally — anchors on untested structure

## Reason

The failing baseline is the spec. It converts skill authoring from opinion into observed-failure remediation, and the recorded rationalizations become the regression tests for the skill.
