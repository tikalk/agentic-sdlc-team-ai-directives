# CDR-008: Failure-type routing (mechanical → check, judgment → rule)

## Context

Eval failures get mis-fixed: teams write prose guidance for mechanically checkable gaps (paying re-derivation cost every session) or write brittle deterministic checks for judgment gaps (false positives erode trust).

## Decision

Route each spec failure by type: mechanical gaps (fixed, checkable patterns) get a deterministic check or unit test — never a prose directive; judgment gaps get a team-directive proposal. Pay once for the check instead of re-deriving it per session.

## Rejected Alternatives

* Prose directives for mechanical gaps — re-derivation cost every session
* Deterministic checks for judgment gaps — brittle, false-positive erosion

## Reason

The routing matches fix durability to failure nature: machines enforce shapes, prose guides judgment. Each fix lands where it compounds instead of where it rots.
